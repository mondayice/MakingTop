# MakingTop · Windows 窗口置顶托盘小工具 — 实施计划（修订版）

## 一、技术选型（含理由）

- **C# / WPF，目标框架 net8.0-windows，SDK 风格项目，`dotnet build` 构建**：执行第一步先用 `winget install Microsoft.DotNet.SDK.8` 正式安装 .NET 8 SDK（你已确认；若无 winget 则回退用 dotnet-install.ps1 官方脚本安装）。本机已有 Desktop Runtime 8.0.19，编译产物直接运行。
- UI 用 **XAML**（托盘菜单样式、悬浮图标窗口）+ C# 逻辑，符合 WPF 惯例、样式可读性好；可用现代 C# 语法。
- **全 Win32 原生 P/Invoke，零第三方依赖**：`Shell_NotifyIcon`（托盘）、`SetWinEventHook`（窗口事件）、`WH_MOUSE_LL/WH_KEYBOARD_LL`（选择模式）、`SetSystemCursor`（图钉光标）。
- .NET 8 WPF 默认 PerMonitorV2 DPI 感知 → 多显示器不同缩放下悬浮图标定位与清晰度都正确。
- **事件驱动、零轮询**：跟随靠 `EVENT_OBJECT_LOCATIONCHANGE` 等 WinEvent 实时驱动 + Dispatcher 合并去重（每帧最多重定位一次），空闲 CPU≈0%，无拖影。

## 三、核心机制设计

**1. 置顶管理（PinManager）** — `Dictionary<hwnd, PinEntry>`（含 overlay 窗口、上次物理矩形、最小化状态）。
`SetWinEventHook(OUTOFCONTEXT|SKIPOWNPROCESS)` 订阅：`LOCATIONCHANGE`（移动/缩放）、`OBJECT_DESTROY`（销毁→自动清 pin+图标）、`OBJECT_REORDER`（层级变化）、`MINIMIZESTART/END`（最小化→隐藏图标，还原→恢复）。回调先做字典 O(1) 查找早退；重定位用脏标记合并到 Dispatcher 单次执行。置顶 = `SetWindowPos(HWND_TOPMOST)`；再选同窗口 = 切换取消（`HWND_NOTOPMOST`）。

**2. 悬浮图标（PinOverlayWindow）** — 无边框透明 WPF 窗口，`WS_EX_NOACTIVATE|WS_EX_TOOLWINDOW`（不抢焦点、不进 Alt+Tab/任务栏）。位置 = 目标窗口**客户区左上角 + (6,6) 物理像素**（天然在标题栏之下，不遮系统按钮），经 `SetWindowPos` 按物理像素定位（多显示器负坐标/跨屏/不同 DPI 均正确，按目标窗口 DPI 缩放内容）。z 序维护：overlay 在 TOPMOST band，再把 target 槽到 overlay 正下方；REORDER 时仅当 `GetWindow(overlay, GW_HWNDPREV) != target` 才重槽（防事件循环）。目标窗口被外部取消置顶（`WS_EX_TOPMOST` 位丢失）→ 静默移除该 pin 与图标。图标本体：24×24、圆角 6、底色 #FDEDEC 85% + #E16259 图钉 Path；点击 = 100ms 缩小动画后取消置顶并关窗（全部取消时所有图标自然消失）。

**3. 选择模式（SelectionService）** — 进入时挂 `WH_MOUSE_LL` + `WH_KEYBOARD_LL`，用 `SetSystemCursor` 把系统箭头换成橙色图钉光标（热点在针尖），退出时 `SystemParametersInfo(SPI_SETCURSORS)` 从注册表还原（异常兜底也还原，光标不残留）。鼠标左键按下：`WindowFromPoint → GetAncestor(GA_ROOT)`，过滤自身窗口/桌面(Progman/WorkerW)/任务栏，然后**吞掉本次点击**（返回1，不误触目标窗口按钮），切换置顶的活儿 Post 给 Dispatcher 后立即出钩（不卡全局鼠标）。Esc 取消选择。点击已置顶窗口 = 取消置顶（toggle）。

**4. 托盘（TrayIconService + TrayContextMenu）** — 隐藏回调窗口接收 `WM_APP+1`，右键弹自定义 WPF ContextMenu（弹出前 `SetForegroundWindow` 修复"点外部不关闭"问题）。监听 `TaskbarCreated` 广播，Explorer 崩溃重启后自动补挂图标。菜单四项：开始选择置顶窗口（进行中可再点取消）/ **取消当前选中窗口置顶**（动态显示窗口标题，如"取消置顶：记事本"，无置顶时禁用）/ 取消所有窗口置顶 / 退出程序（先全部取消置顶——你已确认，再删图标、Shutdown）。

**5. 视觉与动效（按 ui-ux-pro-max / animate 技能规范）** — 色值严格按需求：菜单底 #F7F6F3 圆角 8、文字 #37352F、分割线 #E9E9E7、hover 底 #FDEDEC + 文字 #E16259；图标 hover 态 #FAD2CF + 100% 不透明。动效只做两处（feedback 用途）：hover 颜色/透明度过渡 120ms，点击缩小 100ms（ease-out）——微交互档位，无常驻动画。

## 四、异常与边界清单（全覆盖需求要求）

目标窗口关闭→自动清 pin+图标；最小化→隐藏图标、还原→恢复；移动/缩放→实时跟随；层级被外部改变→重槽或静默清理；单实例互斥体（二次启动直接退出）；全局异常兜底（含光标还原）；无主窗口、无开机自启、仅托盘菜单退出结束进程。
